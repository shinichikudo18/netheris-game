# Netheris: Nexus

Juego Android 2D original ambientado en Netheris.

## V0.1
- Katherine como protagonista
- Exploración táctil en un mapa 2D
- Karen y Karencita como NPC
- Diálogos
- Fragmentos de Nexus coleccionables
- Portal final y condición de victoria
- Reinicio de partida

## Build
La GitHub Action `Build Android APK` compila `app-debug.apk` y lo publica como artifact.

También puede compilarse con:

```bash
gradle assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`
